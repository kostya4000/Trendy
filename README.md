# Trendy — неофициальный клиент PromoDJ

Android-приложение для прослушивания ленты [promodj.com/trendy](https://promodj.com/trendy):
свежие треки, ремиксы, миксы, подкасты и live-записи в одном списке.

## Возможности

- 11 жанров ленты: EDM, Pop/Rock, Hip-Hop, Trance, House, Techno, Bass, Breaks/D&B,
  Hardcore, Ambient, Experimental.
- Фильтры «Всё вместе», «Миксы», «Треки».
- Обложки, исполнитель, тип материала и длительность.
- Фоновое воспроизведение с управлением из уведомления, экрана блокировки и наушников
  (MediaSession).
- Мини-плеер внизу списка и полноэкранный плеер с перемоткой.
- В ландшафте (ТВ, магнитолы, телефон) — постоянный плеер слева и список справа:
  обложка, название, перемотка и кнопки всегда под рукой.
- На ТВ и магнитолах — управление пультом: перемотка стрелками, кнопки
  «Сохранить» и «Скачать» на панели, явное выделение жанра и фильтра.
- Автопереход к следующему треку, обработка ошибок, аудиофокуса и сетевых сбоев.
- Кэш последней ленты: список открывается мгновенно и без сети.
- Скачивание доступных файлов и переход на страницу трека.
- Сохранённая музыка: кнопка «Сохранить» кладёт трек в приватное хранилище
  приложения, а экран настроек показывает занятое место и позволяет слушать
  или удалять сохранённое.
- Работа на Android TV и автомобильных головных устройствах: ландшафтный плеер,
  управление пультом/кнопками и запуск из ТВ-лаунчера.

Приложение не требует регистрации и не обходит платные функции сайта: оно использует
публичные страницы и публичные prelisten-ссылки PromoDJ.

## Сборка

### Вариант 1: готовый APK

```bash
./build.sh
# результат: build/Trendy-<версия>.apk
```

Скрипт собирает всё без Gradle: `aapt2 → javac → d8 → zipalign → apksigner`.
Нужны пакеты Termux:

```bash
pkg install openjdk-21 aapt2 d8 apksigner aapt zip
```

И `android.jar` (API 36):

```bash
mkdir -p .sdk
curl -L -o platform.zip https://dl.google.com/android/repository/platform-36_r01.zip
unzip -j platform.zip android-36/android.jar -d .sdk
```

`android.jar` можно не класть в проект, а задать путь:

```bash
ANDROID_JAR=/path/to/android.jar ./build.sh
```

При первой сборке создаётся `keystore.jks` с паролем `trendy123` — сохраните его,
если планируете выпускать обновления.

### Вариант 2: Android Studio

Откройте каталог проекта в Android Studio и запустите конфигурацию `app`.
Проект использует Gradle-обёртку (Gradle 9.6.0, AGP 9.5.0), но не использует
AndroidX и внешние библиотеки, поэтому зависимостей почти нет.

## Версии

Версия хранится в `version.properties` и читается и `build.sh`, и Gradle.
Перед каждым релизом поднимите её скриптом:

```bash
./tools/bump-version.sh patch   # 1.1 -> 1.1.1
./tools/bump-version.sh minor   # 1.1 -> 1.2
./tools/bump-version.sh major   # 1.1 -> 2.0
```

Скрипт всегда увеличивает `versionCode` на 1 и обновляет `versionName`.

## Релиз

Код живёт в приватном репозитории
[`kostya4000/Trendy`](https://github.com/kostya4000/Trendy). Каждый релиз — новая
версия, тег и APK в GitHub Releases.

```bash
./tools/bump-version.sh patch        # 1.1 -> 1.1.1, versionCode +1
./build.sh                           # build/Trendy-<версия>.apk
git commit -am "Trendy <версия>: <что изменилось>"
git tag -a v<версия> -m "Trendy <версия>"
git push origin main --tags
```

Затем создайте релиз и приложите `build/Trendy-<версия>.apk` и `SHA256SUMS.txt`:

```bash
sha256sum build/Trendy-1.1.apk | awk '{print $1"  Trendy-1.1.apk"}' > SHA256SUMS.txt
```

`keystore.jks` остаётся только локально: он в `.gitignore` и никогда не попадает
в репозиторий, но именно им подписываются обновления.

## Как это работает

1. `PromoDjApi` загружает HTML страницы `/trendy/<жанр>[/<фильтр>]` и вытаскивает
   идентификаторы и ссылки материалов.
2. Метаданные (название, длительность, обложка, ссылки) запрашиваются пакетно через
   публичный `POST /api/multi.json`, метод `players/config`, по 20 файлов за запрос.
3. `PlayerService` разворачивает редирект `prelisten` на подписанный URL CDN,
   играет через `MediaPlayer`, держит foreground-уведомление и `MediaSession`.
4. Список кэшируется в `cacheDir/trendy`, обложки — в `cacheDir/images`.
5. Кнопка «Сохранить» скачивает аудио в `filesDir/audio` (это приватное хранилище
   приложения, система его не вычищает) и пишет рядом JSON с метаданными. При
   следующем запуске `PlayerService` играет локальный файл, а если он повреждён —
   возвращается к сети. Экран настроек показывает сохранённую музыку, временный
   кэш и свободное место, позволяет удалять треки.
6. Аудиофокус запрашивается до старта: при отказе воспроизведение не начинается,
   при временной потере — пауза и возобновление, при ducking — приглушение с
   восстановлением громкости. Состояние `MediaSession` обновляется раз в секунду.

## Структура

```
app/src/main/java/com/promodj/trendy/
  MainActivity.java     лента, жанры, фильтры, мини-плеер
  SettingsActivity.java сохранённая музыка, место, очистка
  PlayerActivity.java   полноэкранный плеер, перемотка, сохранение, скачивание
  PlayerService.java    воспроизведение, аудиофокус, MediaSession, уведомление
  PromoDjApi.java       парсинг ленты + players/config API
  TrackCache.java       офлайн-кэш ленты
  ImageLoader.java      память → диск → сеть для обложек
  Http.java             HTTP-клиент и разворачивание редиректов
  AudioCache.java       сохранённая музыка в filesDir + временный кэш
  Track.java            модель материала
  TrackAdapter.java     список
  SavedAdapter.java     список сохранённых треков
  RoundedImageView.java обложки со скруглёнными углами
  Ui.java               dp, время, размеры, системные бары
tools/MakeIcon.java     генерация launcher-иконок
tools/FileServer.java   локальная раздача APK
tools/bump-version.sh   повышение версии перед релизом
```

## Ограничения

- Нет входа в аккаунт, лайков, комментариев и подписок.
- Скачивание доступно только для файлов, у которых сайт отдаёт публичную ссылку.
- Сохранённая музыка лежит в приватном `filesDir` и не удаляется системой; временный
  кэш (`cacheDir`) и старые файлы можно очистить на экране настроек.
- Лента обновляется по запросу; push-уведомлений о новинках нет.
- Это личный неофициальный клиент. Права на музыку принадлежат авторам и PromoDJ;
  приложение не претендует на аффилированность с сервисом.
